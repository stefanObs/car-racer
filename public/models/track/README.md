# Track kit GLBs

Asphalt-Comic wall and theme scenery modules. Collision stays on the spline ribbon (visuals may overhang).

| File | Use |
|------|-----|
| `tire-wall.glb` | Corner outer walls + `tire_stack` obstacles |
| `concrete-wall.glb` | Straight outer walls + `concrete_barrier` obstacles |
| `fence.glb` | Chain-link panel on top of concrete |
| `crane.glb` | Harbor gantry |
| `container.glb` | Harbor / Baustelle stacks (runtime tint) |
| `tank.glb` | Harbor silo |
| `grandstand.glb` | Parabolbogen yellow tribune |
| `palm.glb` / `hut.glb` | Beach props |
| `tower.glb` / `building.glb` | Schikanenring city |
| `cliff.glb` / `spire.glb` / `scrub.glb` | Omegatal canyon |
| `tree.glb` / `warehouse.glb` | Kuppenfinale forest + sheds |

Rebuild: `npm run track:bake-tripo` (needs gitignored `assets/tripo-out/track/`).
See [SOURCES.md](./SOURCES.md).
