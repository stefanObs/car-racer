# Panorama surround textures

Distant theme surround for sky / horizon cylinders and infield discs (not modelled props).

| File | Use |
|------|-----|
| `harbor-horizon.png` | Havenstadt horizon cylinder wrap |
| `harbor-infield.png` | Havenstadt infield disc (basin) |

Asphalt-Comic plates. Runtime falls back to canvas-painted strips if a PNG is missing.
